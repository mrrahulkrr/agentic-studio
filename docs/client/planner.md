# Guided Release-Date Planner

## 1. Pick a genre
The planner needs to know which films yours would compete with. Choosing a genre pulls the list of everything already scheduled in it.

## 2. Propose a release date
An AI agent reads the release list and tells you which films land within two weeks of your date — the ones that would split your audience.

## 3. Check holidays and events
A second, separate agent checks your date against public holidays in each country plus major sporting events and awards ceremonies. It suggests a clear date per country.

## 4. Adjust and create calendar events
You get the final say on every country's date. Confirming writes a real event to the shared Google Calendar — one per country.
