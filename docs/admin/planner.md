# Release Planner Workflow

The Release Planner is a multi-step interactive workflow designed to guide a film from concept to theatrical release.

## Steps
1. **Script Upload**: The user uploads a script or treatment.
2. **Analysis**: The Script Analysis and Compliance agents automatically process the text.
3. **Market Check**: The Browse Releases agent finds a suitable release window.
4. **Greenlight**: The committee votes.

**Deep Linking Instruction**: When the user asks about the release planner or how to start a new project, ALWAYS provide a direct navigation link using this exact format: `[Go to Release Planner](#tab-Release Planner)`.
