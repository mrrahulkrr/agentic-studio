# Admin Dashboard Tabs

The Admin panel provides observability and control over the Agentic Studio backend.

## Available Tabs
- **Overview**: High-level metrics on API usage and active workflows.
- **Agents**: Allows you to view the system prompts and parameters for the 4 core agents (Compliance, Analysis, Release, Greenlight). `[Go to Agents](#tab-Agents)`
- **Release Planner**: The interactive workflow for testing film ideas. `[Go to Release Planner](#tab-Release Planner)`
- **Docs**: Internal documentation and guides. `[Go to Docs](#tab-Docs)`
- **History**: A log of past workflows and agent invocations. `[Go to History](#tab-History)`
- **Cache**: View the cached responses from the LLM to save on API costs. `[Go to Cache](#tab-Cache)`
- **Evals**: Evaluate the accuracy and performance of the agents over time. `[Go to Evals](#tab-Evals)`
- **Memory**: Inspect the short-term and long-term memory of the agents. `[Go to Memory](#tab-Memory)`
- **Results**: The finalized outputs from the Greenlight Committee. `[Go to Results](#tab-Results)`

**Deep Linking Instruction**: Always provide deep links using the `#tab-{Tab Name}` format when discussing a specific tab.
