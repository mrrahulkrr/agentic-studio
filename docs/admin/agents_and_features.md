# Agents and Features

Agentic Studio uses 4 primary AI agents to automate studio operations.

1. **Compliance Check Agent**: Reviews scripts for global regulatory compliance (e.g., age ratings, forbidden topics in certain regions).
2. **Script Analysis Agent**: Analyzes narrative structure, pacing, and emotional arcs to predict audience reception.
3. **Browse Releases Agent**: Connects to TMDB to view current release schedules and identify congested theatrical windows.
4. **Greenlight Committee Agent**: The final decision-maker that synthesizes the output of the other 3 agents to approve or reject a project.
